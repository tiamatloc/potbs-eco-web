This project is a Economy Production Planner for the Legacy server of the MMO [Pirates of The Burning Sea](https://burningsea.com) and is in the *beta* stage of development. It is based on the original work of Monthar, SirGrey, Remus & the PotBS community.

You can download the release and use it offline (It does not require a login, and all data storage is local to your device), or test it out at [https://tiamatloc.github.io/potbs-eco-web/Production%20Planner.html](https://tiamatloc.github.io/potbs-eco-web/Production%20Planner.html).
